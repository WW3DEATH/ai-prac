Engineered for curiosity.

PHYSICS·LAB is a real-time practical simulation platform built for Sri Lankan Advanced Level Physics students following the NIE English medium syllabus. All 42 prescribed practicals plus a dedicated travelling microscope experiment are implemented as fully interactive browser simulations.

Every simulation renders real lab apparatus — vernier calipers, micrometers, spectrometers, calorimeters, bridges, optical benches, microscopes — not just abstract waves. Type any parameter, press Play, and run the experiment.
